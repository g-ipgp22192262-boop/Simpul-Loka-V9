# Rakaman guru sebenar — Perpustakaan Ajaib

Letakkan rakaman MP3 suara guru sebenar dengan nama fail tepat berikut:

- `dalam-tangan.mp3`
- `ambil-hati.mp3`
- `anak-emas.mp3`
- `air-muka.mp3`
- `mandi-peluh.mp3`
- `cakap-besar.mp3`
- `kitab-ilmu.mp3` (pilihan untuk Kitab Ilmu Utama)

Baca nama dan maksud ringkas, tanpa cerita atau kuiz. Jangan gunakan suara AI/TTS. Tiada MP3 disediakan buat masa ini. `MagicLibrary.audioFiles` dalam `library.js` memetakan laluan. `npm run build` menyenaraikan MP3 yang benar-benar wujud dalam `dist/assets/audio/library-audio.json`; fail JSON ini dijana, bukan diisi dengan rakaman palsu. Selepas menambah rakaman, build semula. Fail yang tiada memaparkan “Audio cikgu akan ditambah”.

Mod Senyap menyekat dan menghentikan rakaman; pertukaran/tutup buku atau keluar halaman turut menghentikannya. Rakaman gagal dimuat ditandakan tidak tersedia. Pastikan rakaman dibenarkan untuk digunakan sebelum dimasukkan.
