# Video panduan guru SimpulLoka V9.1

- `panduan-simpulloka.mp4`: rakaman interaksi aplikasi sebenar, H.264, 1920×1080, 25 fps, 4:40. Tanpa narasi dan tanpa trek audio.
- `panduan-simpulloka.ms.vtt`: sari kata Bahasa Melayu bertanda masa.
- `panduan-simpulloka-poster.png`: bingkai sebenar video, bukan mockup.

Teks penerangan disematkan dalam MP4 supaya muat turun video masih boleh difahami tanpa pemain VTT. Track CC disediakan tetapi tidak diaktifkan secara lalai untuk mengelakkan teks berganda. Pemain tidak autoplay; gunakan kawalan main/jeda, garis masa dan main semula asli pelayar.

Semua data PBD ialah demonstrasi pada simulator setempat yang menjalankan kod GAS sebenar terhadap API dalam memori. Ini bukan bukti sambungan Google Sheets sebenar. Kawalan rakaman Loka 4 menggunakan MediaRecorder sebenar dengan mikrofon ujian pelayar; tiada suara murid, suara guru atau suara AI dalam MP4. Kemajuan enam Loka disediakan melalui API sedia ada untuk menunjukkan syarat Pasport/Sijil, dan dilabel sebagai data demonstrasi.

Lagu Suno asal tidak dimainkan atau dimuat turun untuk video ini. Konsert sebenar menunjukkan pautan yang memang tersedia. Video tidak mendakwa pemain lagu dalaman telah wujud.

Skrip narasi guru dan masa babak berada dalam `docs/video-panduan/`. Rakam narasi sebenar sendiri kemudian. Tiada rahsia, URL Apps Script atau data murid sebenar disertakan.
